# v0.2 Product Plan

> Source: User planning discussion in Cursor chat
> Collected: 2026-05-27
> Published: Unknown

Пользовательский список обновлений для `llh` версии v0.2:

- Оставить термин «сессии».
- Настройки автоматического получения учебных материалов должны храниться для конкретной сессии.
- После основного форматирования/перевода можно включить автоматический запуск перевода слов и грамматики. Это два отдельных OpenAI-запроса.
- Перевод слов и грамматику показывать в основном окне, не в компактном overlay.
- Добавить страницу со списком всех сессий: создать, открыть, удалить, переименовать. Язык сессии менять нельзя.
- Убрать подпись «Движок OCR», сделать сам picker шире.
- В компактном overlay перевода добавить крестик закрытия и закрытие по Escape.
- Если overlay ждёт или отображает дополнительные материалы, авто-скрытие не должно срабатывать; закрытие вручную остаётся через крестик/Escape.
- В режиме «весь текст сессии» добавить раскрытие записей, чтобы можно было увидеть детали и перевод слов, если он есть.
- В списке переводов слева внутри выбранной сессии убрать дату.
- В учебном блоке сделать вкладки «Перевод слов» и «Грамматика».
- Грамматика должна кратко объяснять, как части предложения связаны и почему дают такой смысл, с поправкой на русскоговорящего ученика.
- Убрать вкладки «Сырой текст» и «Форматированный текст». Во время загрузки показывать сырой текст и индикатор; после успеха показывать форматированный текст; при ошибке показывать понятную ошибку и сырой текст.
- Убрать постоянную кнопку «Обновить перевод». Показывать только icon-only retry при ошибке перевода или грамматики, в зависимости от активной вкладки/секции.
- Кнопки «Скрыть сессии» и «Настройки» оставить только иконками.
- В языке сессии показывать иконку/флаг языка рядом с названием.
- В Dock показывать индикатор текущего языка сессии: пустой/нейтральный для автоопределения, флаг для конкретного языка.
- Исправить bug: menu bar `Open Window` не должен открывать бесконечные дубли главного окна, должен активировать уже открытое окно.
- Русифицировать все оставшиеся нерусские строки в приложении.
- Переделать настройки: вместо модального окна сделать отдельную страницу внутри приложения с нормальной шириной, форматированием и вкладками вроде OpenAI и «Общие».
